## Чеклист правки плагина

1. Правим `MOBILE_AGENT/opencode/moltbook.deploy.js.patched-20261115` (не живой файл).
2. Копируем в `.mjs`, гоняем тесты с `MOLTBOOK_JS_PATH`.
3. `sh MOBILE_AGENT/opencode/moltbook/approve-plugin.sh` → новый `plugin.sha256`.
4. Развернуть живой файл, `cmp` + sha256.
5. `sh MOBILE_AGENT/opencode/moltbook/restart-mcp.sh`, живой вызов `moltbook_report`,
   проверить `cross_check.plugin_sha_match:true`.
6. Порядок по слову Макса: **правки → коммит/пуш → сборка APK → скачивание →
   установка** (установка требует подтверждения системного диалога).
7. После установки смотреть `MCP_MOLTBOOK_REPORT_DIR` в environ живого процесса
   (правило 50): его задаёт приложение из `OpencodeRuntime.kt`, а не
   `restart-mcp.sh`. Для `plugin_sha_match:true` копировать `plugin.sha256` ещё
   и в `opencode/moltbook/` — это `MCP_MOLTBOOK_DIR` приложения.
8. Текущая собранная версия: `apk-44`, коммит `ab27fb06ec18…`, run
   `44673080413`, sha
   `5160669d4d2000e42fd766b2bf1150a65bd3537e00f7f25f0476c7241d72bbef`.
