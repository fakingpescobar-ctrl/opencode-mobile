# Волна 3: entity-алиасы и уровень 0 (24.11.2026)

**Статус:** доставлено в **apk-73** (24.11, по слову Макса). Активная сборка —
apk-73; живой `mode:"l0"` проверен через MCP `:4199`. Дефолт по-прежнему
`legacy`. Ниже — локальный замер, на котором решение принималось.

## Зачем открыли волну

План в `архивы/ОБЗОР_СИСТЕМ_ПАМЯТИ_20261120.md` разрешал Волну 3 только при
«реальных провалах на парафразах». Они нашлись на `gold-hard` (20 парафраз):

| запрос | ожидаемый источник | legacy top-5 |
|---|---|---|
| `где лежит эталон плагина и как обновить plugin.sha256` | `ПРАВИЛА.md` | нет (h04) |
| `какой коммит и run собрали apk-45` | `ХАРНЕС.md` | нет (h14) |

Нужный чанк в индексе был — проблема была в ранжировании, а не в покрытии.
Поэтому требовался не эмбеддинг и не LLM, а дешёвый entity-сигнал.

## Что сделано

- `memory-core.js`: `MODES` дополнен `"l0"`. Это **явный opt-in**,
  `DEFAULT_MODE` остаётся `"legacy"`.
- Базовая формула для `l0` побайтно legacy: `v4=false`, UCB=0, те же веса
  FTS5, тот же бюджет якорей 4, evidence 0.02. Над ней один пост-реранкинг
  после дедупа (голова из 20 кандидатов):
  - составной идентификатор запроса (`plugin.sha256`, `runtime/report-dir`,
    `apk-45`) режется на части, каждая часть идёт через тот же
    лемматизатор `analyze()`;
  - покрытие этих entity в уже посчитанных `anchor_fts_v4` чанка даёт бонус
    `0.15 × coverage`;
  - бонус и покрытие видны в `why.entity` — решение объяснимо.
- Никаких новых таблиц, моделей, сетевых вызовов и внешних зависимостей.
  При отсутствии `anchor_fts_v4` — честный fallback на legacy.
- `memory.js`: тулы `memory_pack` и `memory_recall_doc` принимают
  `mode:"l0"` (и ранее пропущенный `mode:"wave2"`).

Абсолютные r5 ниже локальных (0.9735 против 0.9823, held-out 0.9667 против
1.000), потому что живой индекс строится из рабочих доков и имеет иной состав
чанков: g05/g03/g13 выпадают в **обоих** режимах. Это не платёж за l0 и не
регрессия: разница legacy→l0 направлением та же, что и локально.

## Как пользоваться

```json
{ "query": "как обновить plugin.sha256", "mode": "l0" }
```

В MCP `:4199` режим доступен **сейчас**, в установленной apk-73.
Откат — просто убрать `mode` (или поставить `"legacy"`).
