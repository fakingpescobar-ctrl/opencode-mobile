# Манифест уборки `MOBILE_AGENT/tmp/` (20.11)

Причина: после приёмки apk-52 в `tmp/` накопилось 238 записей, около 1.03 ГБ.
Рабочий код, staged-ассеты и актуальная сборка уже есть на GitHub и в телефоне,
поэтому одноразовые скрипты, логи, старые копии БД и куски APK можно убрать.

## Что сделано

- Составлен явный список удаления: `СПИСОК_УДАЛЕНИЯ_TMP.txt`, **213** записей.
- Составлен список оставляемого: `СПИСОК_ОСТАВЛЯЕМОГО_TMP.txt`, **25** позиций.
- Перед удалением создан архив мелких файлов: `архив-уборки-tmp-20261120.tar.gz`,
  `17 511 545` б, sha256
  `cfd53813da1c799f5cb3974768f9e8b2b75fb5e40022f92d01561565e0fd7e9f`,
  630 записей внутри. Архив проверен `gzip -t` и перечислением `tar -tzf`.
  Сам архив лежит локально; на GitHub заливаются только текстовые манифесты
  и списки, чтобы не раздувать репозиторий.
- Полный посчитанный манифест с size/sha по каждой удаляемой записи —
  `МАНИФЕСТ_УБОРКИ_TMP_20261120.tsv` (215 строк: 213 записей tmp плюс
  временный `tmp-cleanup-candidates.txt`).
- Ожидаемая экономия: **1 044 898 КБ** (примерно 1.02 ГБ).

## Восстановление

Мелкие файлы и каталоги восстанавливаются из архива:

```sh
cd /storage/emulated/0/Documents/OpencodeTerminal/MOBILE_AGENT
tar -xzf архивы/архив-уборки-tmp-20261120.tar.gz
```

Крупные APK-файлы брать из GitHub-релиза `apk-51` / `apk-52`, а не из архива.
После распаковки сверить пути по `СПИСОК_УДАЛЕНИЯ_TMP.txt` и хэши по TSV.
