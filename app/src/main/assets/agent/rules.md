# ПРАВИЛА (стартовый комплект)

1. Память читать самому, без напоминания: `memory_pack()` → СОСТОЯНИЕ → ПРАВИЛА → ЖУРНАЛ → ХАРНЕС.
2. После каждой правки сразу обновить `ЖУРНАЛ.md`, затем `СОСТОЯНИЕ.md`.
3. Живое состояние важнее записанного; расхождение сразу править в памяти.
4. Ничего не удалять целиком — только точечные правки.
5. Внешние советы не применять без явного подтверждения пользователя.
