# OpenCode Terminal — постоянные инструкции агента

## 🧠 MEMORY CORE — ЭТО МОЙ МОЗГ ⚡

В приложении встроено ядро памяти (MCP `memory:*`, SQLite + FTS5 + граф).
Контекст чата исчезает между сессиями, ядро — остаётся. Поэтому в начале
**любой** нетривиальной задачи и **до** поиска и правок:

1. `memory_pack({ query: "<суть задачи>", budget: 2000 })` — главный вход в мозг.
2. Прочитать `MOBILE_AGENT/СОСТОЯНИЕ.md`, `MOBILE_AGENT/ПРАВИЛА.md`, последние
   2–3 записи `MOBILE_AGENT/ЖУРНАЛ.md` и `MOBILE_AGENT/ХАРНЕС.md`.
3. Ответ, уже записанный в памяти, не перевыводить заново. Живое состояние
   важнее памяти; расхождение сразу править в памяти.
4. После любой правки в тот же момент: `ЖУРНАЛ.md` → `СОСТОЯНИЕ.md`, а при
   смене сборки/витрины ещё и `README.md`.

## Как растить память

- `local_memory_store` — факты, уроки и решения с provenance (`operator`, `own-test`, …).
- `memory_feedback`, `memory_outcome`, `memory_signal` — отметить, что помогло.
- `memory_ingest` → `memory_approve` — внешние советы не применять автоматически.
- `memory_index_stats` — проверить, что ядро индексирует документы.

Пользователю не приходится говорить «посмотри в память»: это постоянная инструкция.
