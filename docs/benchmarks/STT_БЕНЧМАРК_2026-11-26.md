# STT benchmark — 26.11.2026 (apk-109, OPPO CPH2747)

## Цель
Сравнить локальные STT-движки на одном и том же наборе русских записей Макса (9 фраз, 16 kHz 16-bit stereo PCM WAV, `my_voice_1..9.wav`), охватывающих даты/время, числа, шипящие, Ъ/Ь, имена, аббревиатуры, латиницу, пунктуацию, ё/омонимию и длинную диктовку.

## Метод
- Устройство: OPPO CPH2747, Android 16, apk-109 debug (`org.opencode.mobile.debug`), `versionCode 109`, commit `5b3eda4474c2499aa03635f77425ab1186b59a12`.
- Прогон: debug broadcast `org.opencode.mobile.STT_BENCH` -> `SttBenchReceiver` -> `WhisperTranscribeService.enqueueBench()`.
- Одинаковый ввод: каждый движок получил один и тот же WAV. Исходники были сконвертированы в mono (`*_mono.wav`) в `/data/data/org.opencode.mobile.debug/cache/`, потому что сервис принимает только `16000 Hz, mono, pcm_s16le`.
- Модели/движки: `gigaam-v3-e2e-rnnt` (sherpa_transducer), `parakeet-tdt-0.6b-v3` (sherpa_transducer), `sensevoice-small-int8` (sense_voice), `small` (whisper).
- Метрики: WER/CER после нормализации (lowercase, `ё->е`, удаление пунктуации/кавычек/символов, схлоп пробелов). Сырые гипотезы сохранены отдельно.
- Время: из лога `VOICE:I`: `загрузка мс, проход мс, звук мс, rtf`.

## Ограничения
- Небольшой smoke-набор: 9 клипов, 1 диктор, 1 дубль. Это сравнительный smoke, не статистически полноценный WER-бенч.
- Нормализация скрывает часть различий пунктуации/регистра/ё/кавычек; их нужно смотреть в сырых гипотезах.
- SenseVoice: runtime не подключён в apk-109; все прогоны вернули `ОШИБКА STT: SenseVoice пока не поддержан этим APK (нужен sherpa-onnx sense_voice API)`.
- Первый прогон может включать загрузку модели; смотреть `loadMs/passMs/rtf`.

## Наблюдения
- **GigaAM v3 E2E RNNT**: очень быстрый (RTF 0.052), хорош на обычной русской диктовке, но нормализует даты/время/числа в цифры и местами теряет/склеивает куски (#5 имена/аббревиатуры, #6 числа, #8 «всё ещё и ёж»).
- **Parakeet TDT 0.6B v3 int8**: лучший средний WER/CER на этом smoke-наборе и быстрый (RTF 0.050), но **провал на техтерминах/латинице** в #5: `ООО «ТехСофт», API, MCP, Wi-Fi, OPPO CPH2747` -> `Оо Техсофт ... Апи, Мсипи, Вайфай ... Опо Цп двадцать семь сорок семь` (WER 64.7%).
- **Whisper small**: стабильный базовый вариант, латиницу/бренд в #5 сохранил лучше Parakeet, но медленнее ~в 3.7x (RTF 0.193, avg pass 2544 ms) и средний WER выше (20.0%).
- **SenseVoice small int8**: модель присутствует в `files/stt/sensevoice-small-int8`, но runtime sense_voice не подключён в APK; считать качественным участником нельзя до реализации API-пути.

## Следующие шаги
1. Реализовать/подключить SenseVoice runtime или скрывать как недоступный в UI до поддержки.
2. Сделать большой RU-бенч: разные дикторы, шум, темп, длинные диктовки, отдельные метрики для пунктуации/чисел/латиницы/имён.
3. Для Parakeet проверить post-processing/словарь для латиницы, брендов, аббревиатур.
4. Для GigaAM проверить режим сохранения словесных чисел/дат, если продукту важна дословность.
