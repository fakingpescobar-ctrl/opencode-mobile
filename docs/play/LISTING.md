# Google Play — листинг

Всё, что нужно вбить в Play Console руками, в одном месте. Графика лежит рядом
(`icon-512.png`, `feature-graphic-1024x500.png`, `screenshots/`).

Сборка: `app/build/outputs/bundle/release/app-release.aab`, versionCode **4**,
versionName **0.1.0**, minSdk 28, targetSdk 36.

## Название (до 30 символов)

```

```

## Краткое описание (до 80 символов)

```
ИИ-агент на телефоне: чат, голос, музыка, файлы и приложения
```

60 символов — с запасом.

## Полное описание (до 4000 символов)

```
OpenCode Mobile — нативный клиент ИИ-агента opencode, который работает прямо на вашем телефоне. Приложение само поднимает сервер opencode, поэтому агент получает доступ к рабочей папке: может читать и писать файлы, запускать команды, искать в интернете и управлять приложениями. Без Termux и без root.

ЧАТ

Переписка с моделью в нативном интерфейсе: поле ввода, оптимистичная отправка, автопрокрутка с умной остановкой, индикатор «думает», вибрация по завершении ответа. Если модель просит выбор или разрешение на команду — приложение показывает карточку с вариантами и полем для своего ответа, а не просит угадывать по тексту. Ошибка провайдера видна в ленте с кодом и статусом, а не молчит.

ГОЛОС

Два движка распознавания на выбор: системный Android (быстро, нужен интернет) или локальный whisper.cpp на GPU телефона — офлайн, с автоматическим определением языка и потоковой расшифровкой длинной речи. Озвучка ответов: системный голос, локальная модель Supertonic (офлайн) или облачный ElevenLabs. Если выбранный движок не готов, приложение прямо пишет причину и переключается на запасной.

ИНСТРУМЕНТЫ

Вместе с сервером поднимаются MCP-серверы: локальная память между сессиями, управление телефоном (список и запуск приложений, установка APK, медиатека) и Яндекс Музыка — поиск и включение треков, пауза, лайки, плейлисты, управление текущим плеером. Индикатор в шапке показывает, сколько серверов подключено.

МОДЕЛИ

Модели назначаются по ролям: тяжёлые для сложных многошаговых задач, лёгкие для быстрых ответов, служебные для мелочей. Список доступных моделей приходит с сервера.

ЧЕСТНО О ТРЕБОВАНИЯХ

• Нужен собственный доступ к провайдеру модели (API-ключ или подписка). Приложение не продаёт подписку и не даёт свой ключ.
• Локальное распознавание речи требует разовой загрузки движка (86 МБ) и модели (465 МБ).
• Управление Яндекс Музыкой требует установленного приложения Яндекс Музыка и вашего аккаунта.
• Часть разрешений (доступ к файлам, поверх других окон, специальные возможности для управления плеером) нужна только для перечисленных функций и запрашивается по мере надобности, с объяснением.

ПРИВАТНОСТЬ

Сервер opencode работает на самом телефоне. Переписка и файлы не проходят через наши серверы: запросы уходят напрямую выбранному провайдеру модели. Локальная память хранится в папке приложения на устройстве.
```

## Data safety (черновик ответов)

- Собираются ли данные? **Да** — текст переписки, но только для работы функции.
- Передаётся ли третьим лицам? **Да** — выбранному вами провайдеру модели (это суть работы приложения), не нам.
- Шифрование при передаче: **да** (HTTPS к провайдеру).
- Удаление данных: пользователь удаляет сессии и папку приложения; отдельного запроса на удаление не требуется.
- Реклама и аналитика: **нет**.

## Чего не хватает для публикации

1. **URL политики конфиденциальности** — Play требует его для любого приложения.
   Текст готов: `docs/privacy.md`. Рабочий вариант без настройки Pages —
   <https://github.com/fakingpescobar-ctrl/opencode-mobile/blob/main/docs/privacy.md>.
   Если Play не примет ссылку на blob, включить GitHub Pages (Settings → Pages →
   ветка `main`, папка `/docs`) и указать
   <https://fakingpescobar-ctrl.github.io/opencode-mobile/privacy.html>.
2. **Доступ к Play Console** (аккаунт разработчика) — загрузка AAB и заполнение
   карточки.
3. Проверить, что в release-сборке не осталось debug-подписей и лишних
   разрешений (AAB уже собран и подписан `opencode-release.jks`).
