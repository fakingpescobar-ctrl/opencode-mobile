# Политика конфиденциальности — OpenCode Mobile

Действует с 25.10.2026.

OpenCode Mobile — клиент ИИ-агента opencode, который работает на вашем
устройстве. У приложения нет собственного сервера: разработчик не получает
ваши переписку, файлы, записи голоса и токены.

## Какие данные обрабатываются

**Переписка с моделью.** Текст ваших сообщений и ответы модели отправляются
тому провайдеру модели, чей ключ вы указали в настройках (например, OpenCode
Zen, OpenRouter, DeepSeek). Дальнейшая обработка идёт по правилам этого
провайдера. На устройстве переписка хранится в папке приложения.

**Голосовой ввод.** Если выбран системный движок Android, запись обрабатывается
сервисом распознавания Google. Если выбран локальный whisper.cpp — запись
обрабатывается на устройстве и никуда не передаётся. Записи не сохраняются
после расшифровки.

**Озвучка ответов.** Системный голос работает на устройстве, локальная модель
Supertonic — на устройстве. При выборе ElevenLabs текст ответа отправляется в
ElevenLabs.

**Файлы и команды.** Агент читает и пишет файлы только в рабочей папке, которую
вы ему разрешили, и выполняет команды на самом устройстве. Эти данные никуда не
передаются, кроме случаев, когда вы сами просите агента что-то отправить.

**Яндекс Музыка.** Токен аккаунта хранится на устройстве и используется только
для запросов к сервисам Яндекса от вашего имени. Разработчик к нему доступа не
имеет.

**Локальная память.** Записи памяти агента хранятся в папке приложения на
устройстве.

## Чего приложение не делает

- Не содержит рекламы, аналитики и трекеров.
- Не отправляет отчёты о падениях на серверы разработчика.
- Не собирает идентификаторы устройства, контакты, геолокацию, список
  установленных приложений для передачи наружу. Список приложений читается
  локально и только когда вы просите агента что-то запустить или установить.

## Разрешения и зачем они

| Разрешение | Зачем |
|---|---|
| Доступ к файлам (MANAGE_EXTERNAL_STORAGE) | рабочая папка агента: чтение и запись файлов, которые вы ему поручаете |
| Запись звука | голосовой ввод по нажатию кнопки |
| Специальные возможности (Accessibility) | нажать кнопку воспроизведения в Яндекс Музыке, когда вы просите включить конкретный трек; служба смотрит только окна Яндекс Музыки |
| Поверх других окон | карточка агента и индикатор работы поверх других приложений |
| Уведомления | статус работы сервера и фоновых задач |
| Интернет | запросы к провайдеру модели и сервисам, которые вы используете |

Каждое разрешение запрашивается только при включении соответствующей функции и
может быть отозвано в настройках Android.

## Удаление данных

Переписка, память агента и токены удаляются вместе с данными приложения:
«Настройки Android → Приложения → OpenCode Mobile → Память → Очистить данные»
или удалением приложения. Отдельного запроса разработчику для этого не нужно.

## Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о них
целенаправленно.

# Privacy Policy — OpenCode Mobile (English)

OpenCode Mobile is a client for the opencode AI agent that runs on your own
device. There is no developer-operated backend: we do not receive your chats,
files, voice recordings or tokens.

- **Chat** text is sent to the model provider whose API key you configured, and
  is stored locally in the app's private storage.
- **Speech input** is processed on-device (whisper.cpp) or by Google's speech
  service when the system engine is selected. Audio is not retained.
- **Text-to-speech** runs on-device (system voice, Supertonic) or via ElevenLabs
  if you select it.
- **Files and shell commands** are handled locally inside the workspace you grant.
- **Yandex Music** tokens stay on the device and are used only for requests to
  Yandex on your behalf.
- No ads, analytics, trackers or crash reporting.

Data is deleted by clearing the app's storage or uninstalling the app. Contact:
<https://github.com/fakingpescobar-ctrl/opencode-mobile/issues>.
