## 5. Code Mode: служебный каталог валится в транскрипт (15.11, part31)

- **Симптом:** посреди чата появляется «простыня белого текста» —
  `The Code Mode tool catalog has changed…` + весь каталог инструментов (~150 строк),
  как обычное сообщение, без рамки и без сворачивания.
- **Причина:** MCP-серверы (4199/4200/4201) в этой сборке **одноразовые** — поднимаются
  под вызов и гаснут (`ps`: только процесс приложения, порты закрыты). Каждый цикл меняет
  набор инструментов → харнесс присылает новый каталог → клиент печатает его в чат.
- **Цена:** блок идёт как user-role контент (ест контекст) и повторяется несколько раз в час.
- **Ручки в конфиге нет:** `~/.config/opencode/cli.json` отсутствует; в справочнике V2
  настройки «скрыть напоминания» нет (проверены все группы, включая `experimental`).
- **Для PC:** не рендерить в транскрипт / схлопывать в строку; передавать дельту каталога,
  а не весь список; не считать сменой каталога пересоздание MCP с тем же набором инструментов.
- Детали, доказательства и проверка фикса — `ISSUES_FOR_PC_AGENT_part31.md`.
  Готовый текст upstream-issue — `opencode/opencode-cache/opencode/issue-code-mode-reminder.md`.

**Уточнено 18.11 по факту в журнале сессии (part99 §7) — часть §5 неверна:**

- событие не «несколько раз в час»: за 17–18.11 (с несколькими перезапусками
  MCP) в `session_message` **одно** такое сообщение — 18.11 04:49:06, 8 825 б,
